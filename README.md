# 🚀 Full-Stack Portfolio & CMS Application (MEAN / Modern Web Stack)

A modern, responsive, and dynamic Full-Stack Portfolio Web Application with an integrated **Visual Inline CMS (Admin Mode)** and MongoDB Backend for real-time contact messages and project management.

---

## 🌟 Key Features

* **🎨 Modern Responsive UI / UX**: Clean aesthetics with ambient glow effects, responsive single-page architecture (SPA), and smooth navigation.
* **👑 Live Visual Inline CMS (Admin Mode)**:
  * Passcode-protected live editor directly on the frontend.
  * Live photo and text updates.
* **📬 MongoDB Message Inbox**:
  * Contact form submissions are sent to Express API and stored in MongoDB database.
  * Admin dashboard modal to view and review incoming messages in real-time.
* **🔍 Dynamic Project Filtering**:
  * Category-based interactive filter for portfolio projects and tasks.
* **⚡ RESTful API Backend**:
  * Built with Node.js & Express.js.
  * Modular routes for profiles, posts, and contact messages.

---

## 🛠️ Tech Stack

* **Frontend**: Modern HTML5, CSS3 (Glassmorphism & CSS Variables), JavaScript (ES6+ SPA Router).
* **Backend**: Node.js, Express.js.
* **Database**: MongoDB & Mongoose ORM.
* **APIs**: RESTful Architecture with CORS and JSON middleware.

## 🚀 Getting Started

### 1. Run the Backend:
```bash
cd backend
npm install
npm start
```
*(Backend runs on `http://localhost:5000`)*

### 2. Run the Frontend:
Open `frontend/index.html` with Live Server in VS Code or any web browser.
